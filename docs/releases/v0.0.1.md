The first preview of lumen, a desktop SQL client for PostgreSQL, MySQL, and SQLite with an append-only audit log.

**Install and use:** see the [install and usage guide](https://github.com/phankieuphu/lumen/blob/main/docs/install.md).

## What works

- **Connections** for PostgreSQL, MySQL, and SQLite, tagged Dev / Staging / Production. Passwords live in the system keychain. Read-only mode blocks writes, and production connections ask before any write or schema change.
- **Query editor** with SQL highlighting. Ctrl/⌘+Enter runs the selection or everything, and Cancel stops the query on the server. Rows stream into a virtualized grid (up to 100,000 rows).
- **History** of the statements run on each connection.
- **Relations**: an interactive diagram of tables and foreign keys, with Mermaid export.
- **Audit log** of every write and schema change: hash-chained, verifiable, exportable as CSV or JSON.

## Not yet

- The **slow-query advisor**, **monitor**, and **AI settings** screens are shown but say "not available yet". Their backend arrives in phases 3–5 of the [plan](https://github.com/phankieuphu/lumen/blob/main/docs/plan.md).
- The apps are **not code-signed or notarized** yet. macOS and Windows warn on first launch; the guide shows how to open them.
